pymupdf>=1.28
requests>=2.31
pyyaml>=6.0.2
openpyxl>=3.1

# openpyxl is required, not optional: of the 191 spreadsheets in the 63-paper
# development corpus, 172 are .xlsx, and they are where sample-level metadata
# actually lives. That corpus is not in this repository -- see the note in the
# README about where these counts come from.
#
# The pymupdf floor is the version the checked-in section-score baseline was
# measured on. `tests/expected_section_scores.json` does not reproduce on any
# earlier release -- see the note beside it -- and 1.24.0 has no cp313 wheel at
# all, so the old `>=1.24` was also unsatisfiable on one leg of the CI matrix.
# 1.28.0 ships a cp310-abi3 wheel, so it covers 3.10 through 3.13 from one build,
# and its own `requires_python` is `>=3.10`, matching this project's.
#
# The pyyaml floor is set by wheel availability across the whole supported range,
# not by an API this code needs: cp312 wheels start at 6.0.1 and cp313 wheels at
# 6.0.2, so `pyyaml==6.0` cannot be installed on two of the four interpreters
# `requires-python = ">=3.10"` promises.
#
# The requests and openpyxl floors are NOT load-bearing, and are written down here
# because every other line in this file is read as "this floor exists for a
# reason". The suite passes at requests 2.25.1 and openpyxl 3.0.10, and
# `reset_dimensions` -- the openpyxl call that looks like it would need 3.1 -- is
# present in 3.0.10 and guarded by an except anyway. Keep requests at 2.31
# regardless: that is the release which stopped Proxy-Authorization leaking across
# a cross-host redirect (CVE-2023-32681), and this tool authenticates through an
# institutional proxy, so it is the one dependency where that class of bug would
# reach real credentials.
#
# Two optional extras:
#   requirements-browser.txt   the institutional-proxy tier (Playwright)
#   xlrd>=2.0                  legacy binary .xls supplements (1 of those 191);
#                              without it such a file is reported
#                              `unsupported_format` rather than silently skipped.
#                              No .xls file is in a fetched corpus here, so the
#                              path is exercised against a stub standing in for
#                              xlrd rather than against real bytes.
#
# Word documents, zips and JATS XML need nothing beyond the standard library.
