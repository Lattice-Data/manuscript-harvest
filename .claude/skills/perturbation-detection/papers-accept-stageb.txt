# --- B. dropped, and what that costs -----------------------------------------
# Six papers were cut from a 30-paper draft to 24: the four `yes` papers on
# degraded text (`j.mucimm.2026.03.012`, `j.isci.2021.102151`,
# `s41586-022-04518-2`, `s41586-024-07476-z`), the review
# (`j.coi.2022.102188`), and `j.ccell.2023.08.015`. They were there to prove the
# cap never reaches a non-negative, and that is a CODE invariant, not a model
# behaviour: `task.rules.stage_b` rewrites a "no" and nothing else, and
# `tests/test_harness_guards.py` asserts it over every Stage A value and every
# legal `text_completeness`. Paying the model to re-confirm a parametrized test
# was the weakest $22 in the set.
#
# What it costs, stated rather than glossed: criterion 3 ("no non-negative was
# capped") is now exercised by exactly ONE paper -- `s41586-021-03852-1` in
# group D, which is `unclear` through A5 and whose self-report flipped. If the
# cap ever reached a non-negative, that is where this set would see it.
